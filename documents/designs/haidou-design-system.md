# 海斗速查 · 设计系统

参考对象：虎牙「LOL海斗游戏站」（lolgametool.huya.com）落地页。取其深色竞技底色、金色高亮、悬浮卡片的层次感，不复制其品牌元素。

## 1. 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#07090F` | 页面底色 |
| `--bg-elev` | `#0C101A` | 次级背景 |
| `--panel` | `#111624` | 卡片、面板 |
| `--panel-2` | `#161D2E` | 悬浮层、输入框 |
| `--line` | `rgba(255,255,255,.07)` | 常规分割线 |
| `--line-gold` | `rgba(240,193,91,.24)` | 金色描边 |
| `--gold` | `#F0C15B` | 主强调色，CTA、等级 S |
| `--gold-light` | `#FFE4A8` | 渐变高光、标题 |
| `--gold-deep` | `#C08E33` | 渐变暗部 |
| `--text` | `#F3EFE4` | 主文本（暖白） |
| `--muted` | `#98A0B3` | 次级文本 |
| `--dim` | `#687084` | 弱化标签 |
| `--green` | `#57D98A` | 在线、胜率正向 |
| `--red` | `#EF6A6A` | 负向、风险提示 |
| `--violet` | `#8F7BFF` | 棱彩海克斯、背景辉光 |
| `--cyan` | `#5FD4E8` | 棱彩渐变、数据点缀 |

渐变：
- 金色 CTA：`linear-gradient(180deg,#FFE2A0,#EFBB4C 55%,#D9A03A)`
- 标题金字：`linear-gradient(100deg,#FFF3D0,#F0C15B 48%,#C58F32)`
- 棱彩描边：`linear-gradient(120deg,#8F7BFF,#5FD4E8,#F0C15B)`

## 2. 字体

- 正文/标题：`"PingFang SC","Microsoft YaHei UI","Noto Sans SC",system-ui`
- 数字/英文标签：`"Bahnschrift","DIN Alternate","Segoe UI"`，`font-variant-numeric: tabular-nums`
- 标题字重 800，字距 `-.02em`；小标签 11-12px，字距 `.14em`，全大写英文。

## 3. 尺寸与间距

- 页面内容宽 `1240px`，左右留白 `24px`
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64
- 圆角：卡片 16px，小控件 10px，药丸 999px
- 卡片：`1px solid var(--line)`，悬停转金色描边 + 上移 4px
- 阴影：`0 24px 60px rgba(0,0,0,.45)`；金色 CTA 阴影 `0 8px 30px rgba(240,193,91,.25)`

## 4. 组件

- **顶栏**：68px，半透明 + 12px 背景模糊，底部 1px 分割线；激活项金色 + 下方 4px 光点。
- **英雄卡**：4:5 竖版加载图，底部渐黑；左上梯度徽章（T1 金 → T5 灰），底部胜率/选取率；悬停放大 1.04。
- **海克斯卡**：48px 六边形图标（clip-path），稀有度决定描边渐变；右上 S/A/B/C 徽章；底部选取率进度条。
- **出装卡**：6 个 40px 装备图标，前 3 件带金色角标；元信息用等宽数字。
- **悬浮窗**：360-420px 宽，`backdrop-filter: blur(18px)`，85% 不透明深色，金色 1px 内描边，出现动画 220ms `cubic-bezier(.22,1,.36,1)`。

## 5. 动效

- 入场：`opacity 0→1 / translateY(14px→0)` 420ms，卡片按序 40ms 递延
- 悬停：160ms；进度条填充 600ms ease-out
- 尊重 `prefers-reduced-motion`

## 6. 布局断点

- ≥1080：双栏（内容 + 侧栏）、英雄卡 5-6 列
- 900-1080：英雄卡 4 列，详情转单栏
- 640-900：英雄卡 3 列，顶栏导航收起，显示底部 5 项导航
- <640：英雄卡 2 列，区块间距 48px，CTA 全宽
